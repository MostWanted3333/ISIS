# ISIS


Веб-приложение для подготовки к собеседованиям с использованием искусственного интеллекта.

## Описание проекта

Данный проект представляет собой веб-сервис, который помогает пользователю подготовиться к прохождению собеседований.  
Приложение позволяет регистрироваться, работать с личным кабинетом и хранить данные в базе данных.

В рамках проекта реализована базовая серверная логика, взаимодействие с базой данных и пользовательский интерфейс.

---

## Функциональность

- Регистрация пользователя  
- Личный кабинет (dashboard)  
- Хранение данных в базе данных  
- Работа с несколькими сущностями:
  - пользователи
  - резюме
  - вакансии
  - навыки
  - интервью
  - ответы
  - план подготовки  

---

## Стек технологий

- Backend: FastAPI  
- ORM: SQLAlchemy  
- База данных: SQLite  
- Шаблоны: Jinja2  
- Frontend: HTML, CSS  
- Асинхронность: async/await
